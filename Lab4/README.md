## Описание

В рамках лабораторной работы реализовано локальное сохранение данных:
SwiftData для экрана Список фильмов
При открытии экрана юк Получить список обращается к репозиторию, в котором осуществляется проверка: если кэш есть - показываем кэш, иначе выполняем сетевой запрос (в текущей реализации мок).
Также в навигационном баре доступны кнопки - принудительный запуск юк Получить список и удалить весь список.

UserDefaults для сохранения значения тогла Скрывать спойлеры.
Булевское значение сохраняется и переиспользуется при открытии разных фильмов

SwiftData для экрана Просмотренные интересные факты
Записываем в хранилище историю просмотренных фактов. Доступно удаление отдельного факта.
