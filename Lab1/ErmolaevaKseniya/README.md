## Задание 1. 

На основе массива заказов `Order` выполнить следующие операции с использованием функциональных возможностей Swift:

1. Получить суммы оплаченных заказов с помощью `filter` и `map`.
2. Вычислить общую сумму неоплаченных заказов с помощью `reduce`.
3. Получить отсортированный список уникальных клиентов.
4. Извлечь промокоды, исключив `nil`, с помощью `compactMap`.
5. Сгруппировать заказы по клиентам с помощью `Dictionary(grouping:by:)`.
6. Найти клиента с максимальной суммарной стоимостью оплаченных заказов.

**Реализация:** `Task1.swift`

## Задание 2. 

Реализовать структуры `Point` и `Rectangle`.

- `Point`: перемещение точки, вычисление расстояния до начала координат, соответствие `Equatable` и `Hashable`.
- `Rectangle`: вычисление площади, периметра и центра, масштабирование, проверка принадлежности точки и валидация размеров при инициализации.

**Реализация:** `Task2.swift`
