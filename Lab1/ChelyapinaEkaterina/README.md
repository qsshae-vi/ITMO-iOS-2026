Решение задач:
1) На основе массива заказов Order выполнить следующие операции с использованием функциональных возможностей Swift:
- Получить суммы оплаченных заказов с помощью filter и map.
- Вычислить общую сумму неоплаченных заказов с помощью reduce.
- Получить отсортированный список уникальных клиентов.
- Извлечь промокоды, исключив nil, с помощью compactMap.
- Сгруппировать заказы по клиентам с помощью Dictionary(grouping:by:).
- Найти клиента с максимальной суммарной стоимостью оплаченных заказов.
```
struct Order {
    let id: Int
    let customer: String
    let amount: Double // сумма заказа

}

```
