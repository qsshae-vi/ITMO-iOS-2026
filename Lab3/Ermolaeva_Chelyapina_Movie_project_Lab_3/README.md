## Описание

В рамках лабораторной работы заложена основа проекта - iOS-приложения для просмотра информации о фильмах с использованием SwiftUI.

Выбрана архитектура MVVM, организована начальная структура проекта, реализованы навигация между экранами и внедрение зависимостей (Dependency Injection). Начата разработка пользовательского интерфейса и сетевого взаимодействия с Kinopoisk Unofficial API.

## Архитектура

Приложение построено с использованием **MVVM** и разделения на слои:

- **Domain** - модели и интерфейсы бизнес-логики, Use Cases.
- **Data** - реализация работы с API и локальным хранилищем.
- **Presentation** - SwiftUI-представления и ViewModel.

## Структура проекта

- `App/` - точка входа и настройка зависимостей.
- `Core/Network/` - сетевой сервис.
- `Features/FilmList/` - модуль списка фильмов.
- `Features/OneFilm/` - экран информации о фильме.
- `Features/FunFact/` - модуль интересных фактов.
- `Navigation/` - маршрутизация между экранами.

## Запуск проекта

1. Открыть `MobDevIosKino.xcodeproj` в Xcode.
2. Создать файл `Secrets.xcconfig` на основе `Secrets.example.xcconfig`.
3. Указать собственный API-ключ Kinopoisk Unofficial в параметре `KINOPOISK_API_KEY`.
4. Выбрать симулятор iPhone и запустить приложение.

Файл `Secrets.xcconfig` с API-ключом исключён из Git с помощью `.gitignore`.

## Требования

- iOS 17.0 и выше.
- Xcode для сборки и запуска проекта.
