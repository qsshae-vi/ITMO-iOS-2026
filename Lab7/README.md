## Описание

В рамках лабораторной работы реализованы UI- и Unit-тесты.  

UI-тесты:
- test_tapFilm_opensDetail - проверяет, что при тапе по первой карточке фильма в списке открывается экран деталей фильма (filmDetail.screen).
- test_searchTyping_showsCards - проверяет сценарий поиска: открытие экрана поиска по кнопке, ввод запроса «матрица» в поле поиска и появление хотя бы одной карточки результата (searchFilm.card.*).
