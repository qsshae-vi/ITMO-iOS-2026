## Описание

В рамках лабораторной работы реализована многопоточность.  Для этого добавлена функциональность Поиск фильмов:
- @MainActor @Observable SearchViewModel - состояние UI изолировано на главном акторе, наблюдение через Observation.
- Debounce 300 мс - поиск запускается не на каждое нажатие, а после паузы в вводе (Task.sleep); предыдущая задача отменяется.
- Отмена устаревших запросов - searchTask?.cancel() + проверки Task.isCancelled и currentKeyword == keyword защищают от гонок и применения устаревших ответов.
- Минимальная длина запроса (2 символа) - короткие запросы не отправляются на сервер, состояние сбрасывается в .idle.
- Пагинация с защитой от дублей - подгрузка следующей страницы при появлении одного из последних 3 элементов (loadNextPageIfNeeded); уникальность фильмов обеспечивается через Set<ID> при первой загрузке и при склейке страниц.
- Защита от повторного запроса - isLoadingNextPage и сравнение с lastCompletedKeyword предотвращают лишние сетевые вызовы.
- Явные состояния экрана - idle / searching / loaded / empty / error, каждому соответствует свой UI; ошибки NetworkError маппятся в пользовательское сообщение с кнопкой «Повторить».
