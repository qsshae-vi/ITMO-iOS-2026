# Лабораторная работа № 6. Работа с сетью и обработка ошибок

**Выполнили:**
- Ермолаева Ксения
- Челяпина Екатерина

**Группа:** К4140

## Описание
В процессе выполнения Лабораторной работы №6:
- Доработан слой репозитория: вместо моковых данных фильмы загружаются через API.
- В NetworkServiceImpl добавлена обработка сетевых ошибок (URLError), HTTP-кодов ответа (statusCode) и ошибок декодирования полученных данных.
- Применены кастомные типы ошибок.
- Обновлена логика отображения при отсутствии интернет-соединения и возникновении других ошибок: при невозможности загрузить данные из сети пользователю остаются доступны ранее сохранённые факты о фильмах; реализовано отображение соответствующих сообщений об ошибках.
